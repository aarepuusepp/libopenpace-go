
# NFC + PACE + Secure Messaging Debug Plan (Thales test card, ACR1252U)

## TL;DR
- Your PACE completes and yields `K_enc`/`K_mac`, so the key agreement is good.
- Every **SM-protected** command returns `SW=6999` → almost always **SM construction** issue (wrong MAC input, wrong SSC, wrong presence/order of DO87/DO97/DO8E, or spurious `Le'`).
- Fixes:
  1) **Select the applet by AID** right after PACE (inside SM), then `DFDD`, then the PD EFs (5001/5002/5006…).  
  2) **Initialize SSC from PACE**, not zero.  
  3) For **AES-CMAC**: **do NOT ISO-pad** `SSC || M` yourself—CMAC defines its own padding.  
  4) **Do not append `Le'` (0x00) unconditionally.** In protected commands, use **DO97** to carry Le; omit `Le'` unless the stack explicitly requires it.

## Correct high-level sequence (NFC)
1. **PACE(CAN)** → get `K_enc`, `K_mac`, **`SSC0` (initial SSC)**, algorithm = AES-128 CMAC (your log shows that)  
2. From now on, every APDU must be **SM-protected** with **CLA = CLA|0x0C** and wrapped as case 1S/2S/3S/4S:  
   - Case 1S (no data, no Le): data field contains **DO8E only**  
   - Case 2S (Le only): **DO97 + DO8E**  
   - Case 3S (Lc only): **DO87 + DO8E** (ciphertext in DO87)  
   - Case 4S (Lc + Le): **DO87 + DO97 + DO8E**  
3. **SELECT AID** `A0 00 00 00 63 50 4B 43 53 2D 31 35` (SM) → `9000`  
4. **SELECT DFDD** path (`00 A4 08 0C 02 DF DD`) (SM) → `9000`  
5. For each PD EF: `SELECT EF 500x` (SM) → `READ BINARY`(SM). For `READ BINARY`, first send with `Le=00` and expect `6Cxx`, then re-issue with `Le=xx`.
6. Responses: card returns **DO99 (status)** and **DO8E (MAC)** and optionally **DO87 (data)** under SM; verify CMAC, decrypt DO87, parse DO99→SW.

## Review of your SM code and what to change

### 1) SSC initialization
`NewContext` currently sets `SSC := 0x0000000000000000` and you `IncrementSSC()` before each command. For PACE SM you must start from the **initial SSC generated by PACE**, not zero. Provide it from your OpenPACE side.

> **Change**: `NewContext(encKey, macKey, sscInitial []byte)` and set `ctx.SSC = sscInitial` (8 bytes). If you keep `NewContext(enc, mac)`, add a `SetSSC([]byte)` method and **call it** once, right after PACE.

### 2) CMAC input padding (AES)
In `WrapCommand` and `UnwrapResponse` you perform **ISO9797 Method 2 padding** **before** calling `crypto.CMAC`. CMAC already defines its own padding; **double padding breaks MAC** and yields `0x6999` for every command.

> **Change**: Remove ISO padding for CMAC; compute CMAC directly over `SSC || M` (commands) and `SSC || R` (responses). Keep ISO9797 Method 2 only for **ciphertext DO87** payload (CBC data).

### 3) `Le'` handling
You currently **always** append `Le' = 0x00` in `WrapCommand`, even when no Le and even when DO97 was added. Some cards tolerate it; Thales/Cosmo-X will reject protected commands with an unexpected `Le'` → `0x6999`.

> **Change**: Only append `Le'` **when required**. If you included DO97, **omit** `Le'`. For Case 1S (only DO8E), also **omit** `Le'`.

### 4) Command MAC header
You set `CLA' = CLA|0x0C` both in header and MAC input—good. Ensure **DO order** is `[DO87] [DO97] DO8E` and that **Lc'** equals length of those DOs (not counting `Le'` if omitted).

### 5) Response MAC input
For responses, the MAC input is `SSC || [DO87][DO99]` (no DO8E). You do that, but you add ISO9797 padding before CMAC—remove that (see #2).

### 6) AES/3DES selection
You default to AES (good; PACE used AES per your log). If you ever fall back to 3DES, you must switch to **Retail MAC (ISO 9797-1 Alg. 3)** instead of CMAC. For now keep AES only.

### B) WrapCommand (remove CMAC pre‑padding; fix Le')
```go
func (ctx *Context) WrapCommand(cla, ins, p1, p2 byte, data []byte, le int) ([]byte, error) {
    ctx.IncrementSSC()

    var dataObjects []byte

    if len(data) > 0 {
        enc, err := ctx.encryptData(data) // uses ISO9797-2 + CBC with IV=0
        if err != nil { return nil, err }
        do87 := buildDO(0x87, append([]byte{0x01}, enc...))
        dataObjects = append(dataObjects, do87...)
    }

    // Only include DO97 when caller provided Le
    if le > 0 {
        b := []byte{byte(le)}
        if le == 256 { b = []byte{0x00} }
        do97 := buildDO(0x97, b)
        dataObjects = append(dataObjects, do97...)
    }

    // CMAC over SSC || (CLA' INS P1 P2 || DOs)
    header := []byte{cla | 0x0C, ins, p1, p2}
    macInput := make([]byte, 0, 8+4+len(dataObjects))
    macInput = append(macInput, ctx.SSC...)
    macInput = append(macInput, header...)
    macInput = append(macInput, dataObjects...) // NO ISO padding here for CMAC

    macFull, err := crypto.CMAC(ctx.MACKey, macInput)
    if err != nil { return nil, err }
    do8e := buildDO(0x8E, macFull[:8])

    // Protected APDU data = DO87 [DO97] DO8E
    protected := make([]byte, 0, 4+1+len(dataObjects)+len(do8e))
    protected = append(protected, header...)
    Lc := len(dataObjects) + len(do8e)
    protected = append(protected, byte(Lc))
    protected = append(protected, dataObjects...)
    protected = append(protected, do8e...)
    // NO Le' unless your stack empirically requires it; if so, add only when le==0
    return protected, nil
}
```

### C) UnwrapResponse (remove CMAC pre‑padding)
```go
func (ctx *Context) UnwrapResponse(resp []byte) ([]byte, uint16, error) {
    if len(resp) < 2 { return nil, 0, fmt.Errorf("short response") }
    if len(resp) == 2 { return nil, binary.BigEndian.Uint16(resp), nil }

    ctx.IncrementSSC()

    data := resp[:len(resp)-2]
    sw := binary.BigEndian.Uint16(resp[len(resp)-2:])

    var encData, do99, mac []byte
    pos := 0
    for pos < len(data) {
        tag := data[pos]; pos++
        l, n := parseDOLength(data[pos:]); pos += n
        val := data[pos:pos+l]; pos += l
        switch tag {
        case 0x87:
            if len(val) == 0 || val[0] != 0x01 { return nil, 0, fmt.Errorf("bad DO87") }
            encData = val[1:]
        case 0x99:
            do99 = val
        case 0x8E:
            mac = val
        }
    }
    if len(mac) != 8 { return nil, 0, fmt.Errorf("missing/short DO8E") }

    // CMAC over SSC || (all DOs except DO8E), NOT padded for CMAC
    macInput := make([]byte, 0, 8+len(data)-len(mac))
    macInput = append(macInput, ctx.SSC...)
    macInput = append(macInput, data[:len(data)-len(mac)-2]...) // exclude DO8E (tag+len+val)

    macFull, err := crypto.CMAC(ctx.MACKey, macInput)
    if err != nil { return nil, 0, err }
    if !bytes.Equal(mac, macFull[:8]) {
        return nil, 0, fmt.Errorf("MAC verification failed")
    }

    var plaintext []byte
    if len(encData) > 0 {
        p, err := ctx.decryptData(encData)
        if err != nil { return nil, 0, err }
        plaintext = p
    }
    if len(do99) == 2 {
        sw = binary.BigEndian.Uint16(do99)
    }
    return plaintext, sw, nil
}
```
